# خطة النشر على Netlify

تم إعداد المشروع بنجاح ليكون جاهزًا للرفع على GitHub والنشر تلقائيًا عبر Netlify.

## 1. تحليل المشروع
- **نوع المشروع:** React (Vite)
- **مجلد البناء:** `dist`
- **أمر البناء:** `npm run build`

## 2. الملفات التي تم إنشاؤها
### أ. ملف إعدادات Netlify (`netlify.toml`)
يحتوي هذا الملف على التعليمات التي يحتاجها Netlify لبناء الموقع وتشغيله بشكل صحيح، بما في ذلك:
- تحديد أمر البناء (`npm run build`).
- تحديد مجلد النشر (`dist`).
- حل مشكلة التوجيه (Routing) في تطبيقات الصفحة الواحدة (SPA) لضمان عدم ظهور أخطاء 404 عند تحديث الصفحة.

### ب. ملف الرفع التلقائي (`deploy_to_github.bat`)
سكربت تنفيذي يقوم بالخطوات التالية بضغطة زر:
1. تهيئة Git (إذا لم يكن موجودًا).
2. ربط المشروع بالمستودع: `https://github.com/Farouk-eladawy/tourcare.ai2`
3. إضافة جميع الملفات.
4. الرفع المباشر (Push) إلى الفرع `main`.

## 3. كيفية الاستخدام
1. قم بتشغيل الملف `deploy_to_github.bat` (انقر عليه مرتين).
2. انتظر حتى تظهر رسالة اكتمال الرفع.
3. اذهب إلى حسابك في Netlify، واختر "New site from Git"، ثم اختر هذا المستودع.
